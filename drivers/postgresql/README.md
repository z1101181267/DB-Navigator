# PostgreSQL JDBC Driver

Place the following JAR files in this directory:

## drivers/postgresql/42.7.13/ (Active)
- `postgresql-42.7.13.jar` — PostgreSQL JDBC Driver 42.7.13
  - Download: https://central.sonatype.com/artifact/org.postgresql/postgresql/42.7.13
  - Maven: `org.postgresql:postgresql:42.7.13`

## Driver Class
```
org.postgresql.Driver
```

## Connection URL Example
```
jdbc:postgresql://192.168.1.100:5432/mydb
```

## Default Port
5432
